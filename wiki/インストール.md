# インストール

## 必要なもの

- Windows 10 または 11（64 ビット）
- NFC リーダー（PC/SC 対応のもの。対応の範囲は [[対応リーダーとタグ]]）。リーダーが無くても、[[仮想リーダー]]で試せます。
- Windows の「Smart Card」サービス（ふだんは自動で動きます）

## ダウンロード

[Releases](https://github.com/UnlitCube/nfc-tag-studio/releases) の一覧から、いちばん上の版の「Assets」を開き、次のどちらかをダウンロードします。

| ファイル | 使い方 |
|---|---|
| `NFC-Tag-Studio-<版>-win-x64-portable.exe` | ダブルクリックでそのまま起動します（インストールは不要）。起動のたびに一時フォルダへ展開するので、起動に数秒かかります。 |
| `NFC-Tag-Studio-<版>-win-x64.zip` | 好きな場所に展開し、中の `NFC Tag Studio.exe` を起動します。起動が速く、USB メモリに入れて持ち運べます。 |

0.x の間は、ベータ版（プレリリース）として公開しています。

### ダウンロードしたファイルを確かめる（任意）

同じ場所の `SHA256SUMS.txt` に、各ファイルの SHA-256 が書いてあります。PowerShell で次を実行し、表示された値が一致することを確かめます。

```powershell
Get-FileHash .\NFC-Tag-Studio-<版>-win-x64-portable.exe -Algorithm SHA256
```

## 初めて起動するとき（SmartScreen）

配布物にはコード署名をしていないため、初めて起動すると「Windows によって PC が保護されました」と出ることがあります。

1. ［詳細情報］を押します。
2. アプリの名前が `NFC Tag Studio.exe`（portable なら `NFC-Tag-Studio-…-portable.exe`）であることを確かめて、［実行］を押します。

会社の PC で起動できないときは、PC の管理者に、上のファイルの実行を許可してもらってください。

## Sony PaSoRi を使うとき

Sony の「NFC ポートソフトウェア」を入れてから、PaSoRi を USB に接続します。PaSoRi は、スリープから復帰した後などに認識されなくなることがあり、USB を抜き差しすると戻ります（[[トラブルシューティング]]）。

## データの保存場所

設定・登録した鍵・発行台帳は、次のフォルダに保存します（portable 版・zip 版とも同じ）。

```text
%APPDATA%\NFC Tag Studio
```

| ファイル | 中身 |
|---|---|
| `settings.json` | 設定（使うリーダー・表示など） |
| `keys.json` | 登録した MIFARE の鍵（Windows の資格情報の保護（DPAPI）で暗号化。別の PC・別のユーザーでは開けません） |
| `issue-log.json`・`issued-uids.tsv` | 発行台帳（鍵・パスワードは入れません） |
| `issue-last-run.json` | 一括発行の「続きから再開」のための情報 |

## アンインストール

インストーラーは使っていないので、次の 2 つを消せば元に戻ります。

1. ダウンロードした exe、または展開した zip のフォルダ
2. `%APPDATA%\NFC Tag Studio`（設定・鍵・発行台帳。残したいときは消さない）
