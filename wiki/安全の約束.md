# 安全の約束

このアプリは、**管理・運用する権限を持っているタグ**のための道具です。他人のカードの不正な複製や、認証の回避には使えない作りにしています。

## 想定する使い方

- 自組織の社員証・勤怠タグ・会員証などに、社員 ID や会員番号を採番して発行する
- 自分のタグのデータ領域をバックアップし、別の空のタグに書き戻す・複製する
- NFC タグに URL・Wi-Fi の設定・連絡先などの NDEF を書き込む

## このアプリがすること・しないこと

| 約束 | 中身 |
|---|---|
| UID を書き換えない | UID（製造番号。FeliCa では IDm）は読み取り専用として扱います。NTAG のページ 0〜1・MIFARE のブロック 0 は、どの設定でも書き込みません。UID を書き換える特殊なタグ（いわゆる magic card）向けの機能はありません |
| 鍵を解析しない | MIFARE Classic は、運用者が登録した鍵でだけ開きます。鍵の解析・総当たりはしません |
| 秘密を残さない | 鍵とパスワードは、ログ・発行台帳・バックアップのファイル・エラーの詳細に残しません |
| 取り消せない操作は確かめてから | ロックビット・CFGLCK・パスワードの設定・MIFARE のアクセス条件・FeliCa の書込保護は、上級者モードと確認（重いものは語の入力）を経てからでないと実行できません |
| NFC でない機器には送らない | USB セキュリティトークンなど、NFC リーダーと判定できない PC/SC 機器には、運用者が選ばない限りコマンドを送りません |
| 書いたら確かめる | 書き込みの後に読み戻して照合し、書けなかったページ・ブロックと次にすることを示します |

## UID について

UID は、タグの製造時に書き込まれ、以後は読み取り専用です。そのため、タグを「複製」しても UID は複製されません。複製できるのは、書き込みできるデータ領域（ユーザーメモリ・NDEF）だけです。

UID だけで本人を確かめる入退室のシステムは、タグを複製しても別の UID になるため、そのままでは通りません。UID は秘密の値ではないので、UID だけを認証に使う運用そのものにも注意が要ります。データ領域の内容（社員 ID など）やサーバー側の許可リストで判定する運用が、複製・再発行に向いています。

## 他人の交通系 IC や社員証を複製できますか

できません。それらは鍵で保護されており、UID も固定です。このアプリは、鍵を管理している自組織のタグを発行・編集するためのものです。

## 脆弱性を見つけたとき

公開の Issue には書かず、[セキュリティポリシー](https://github.com/UnlitCube/nfc-tag-studio/security/policy) の手順で知らせてください。
