Issue and edit your organization's NFC tags.

A Windows desktop app to read, edit, write, back up and batch-issue NTAG213/215/216, MIFARE Classic and FeliCa Lite-S tags — for numbering employee and member cards, or writing URLs and Wi-Fi settings.

Features

Place a tag and it is read automatically; every screen shows the tag on the reader the same way. Before writing, the app shows the target tag (type and UID).

NDEF editor

Compose URLs, text, Wi-Fi settings, contacts, app launch records and more that phones can read, and write them.

Binary editor

Edit memory byte by byte with colour-coded areas, explanations of bits, counters and a guided settings editor.

Batch issue

Write sequence numbers, CSV rows or NDEF to one tag after another, with skipping of issued tags, verification, resume and an issue log.

Backup & duplicate

Save a tag to .nfcdump, .bin or Flipper .nfc and write it back to the same or another tag (the UID is never copied).

Data schema

Lay out where and how an ID is written on the tag, save it as a file and use it for batch issue.

MIFARE keys

Register the keys you operate. They are masked on screen and stored encrypted with Windows DPAPI.

Safety by design

A tool for tags you are authorized to manage. It is built so that it cannot be used to clone other people's cards or bypass authentication.

  • The UID is never writtenThe UID (serial number) is read-only. There is no support for UID-changing "magic" cards.
  • No key crackingMIFARE Classic sectors open only with keys the operator registers. No brute force or key recovery.
  • No secrets left behindKeys and passwords never go into logs, the issue log or backup files.
  • Irreversible steps need confirmationLocking and password settings require advanced mode and an explicit confirmation.
  • Nothing sent to non-NFC devicesPC/SC devices that are not NFC readers, such as USB security tokens, never receive commands.
  • Writes are verifiedEvery write is read back and compared; failures show which pages or blocks were not written and what to do next.

Getting started

  1. Download and runGet the portable exe or the zip from Releases and start it — no installation needed.
  2. Connect a readerFor a Sony PaSoRi, install "NFC Port Software" first. No reader? Use the virtual reader.
  3. Place a tagKeep it on the reader; it is read automatically. Edit it in the NDEF or binary editor and press "Write to tag".

The executables are not code-signed, so Windows SmartScreen asks for confirmation the first time.

Current limitations

  • Windows (x64) only. There are no macOS or Linux builds.
  • Storage-type readers such as the Sony PaSoRi cannot do NTAG password authentication, NFC counters or signature reads.
  • ACR122U-type readers and MIFARE Classic have been checked with the virtual reader only.
  • FeliCa support is limited to FeliCa Lite-S (no transit cards).
