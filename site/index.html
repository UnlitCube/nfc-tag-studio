自組織の NFC タグを、迷わず発行・編集する。

NTAG213/215/216・MIFARE Classic・FeliCa Lite-S を、読み取り・編集・書き込み・バックアップ・一括発行する Windows のデスクトップアプリです。社員証や会員証への ID の採番、URL や Wi-Fi の書き込みに使えます。

ダウンロード 使い方を読む

v{{VERSION}}（ベータ版）・Windows 10 / 11（x64）・インストール不要の exe と zip

できること

タグを置くと自動で読み取り、どの画面でも「リーダーの上のタグ」の状態が同じ表示で出ます。書き込む前には、書き込み先のタグ（種類と UID）を確かめます。

NDEF 編集

URL・テキスト・Wi-Fi・連絡先・アプリの起動など、スマートフォンで読める内容を作って書き込みます。

バイナリ編集

メモリを 1 バイトずつ編集します。領域の色分け、ビットの意味の解説、連番の増減、設定の解説つき編集。

一括発行

連番・CSV・NDEF を、タグを置き替えながら 1 枚ずつ書き込みます。発行済みのスキップ、照合、止めた所から再開、発行台帳。

バックアップ・複製

タグの内容を .nfcdump・.bin・Flipper の .nfc に保存し、同じタグや別のタグに書き戻します（UID は複製されません）。

データスキーマ

社員 ID などを、どの位置にどの形式で書くかを画面で組み立て、ファイルに保存して一括発行で使います。

MIFARE 鍵の管理

運用している鍵を登録します。伏字で表示し、Windows の資格情報の保護（DPAPI）で暗号化して保存します。

対応リーダーとタグ

PC/SC（Windows の「Smart Card」サービス）で NFC リーダーと通信します。リーダーが無くても、仮想リーダーで一通り試せます。

安全の約束

管理・運用する権限を持っているタグのための道具です。他人のカードの複製や、認証の回避には使えない作りにしています。

  • UID は書き換えないUID（製造番号）は読み取り専用です。UID を書き換える特殊なタグ（magic card）向けの機能はありません。
  • 鍵を解析しないMIFARE Classic は、運用者が登録した鍵でだけ開きます。総当たりや解析はしません。
  • 秘密を残さない鍵とパスワードは、ログ・発行台帳・バックアップのファイルに残しません。
  • 取り消せない操作は確かめてからロックやパスワードの設定は、上級者モードと確認を経てからでないと実行できません。
  • NFC でない機器には送らないUSB セキュリティトークンなど、NFC リーダーでない PC/SC 機器にはコマンドを送りません。
  • 書いたら確かめる書き込みの後に読み戻して照合し、書けなかったページ・ブロックと次にすることを示します。

はじめかた

  1. ダウンロードして起動Releases から portable の exe か zip を取り、そのまま起動します（インストールは不要）。
  2. リーダーを USB に接続Sony PaSoRi なら「NFC ポートソフトウェア」を入れておきます。リーダーが無ければ、仮想リーダーで試せます。
  3. タグを置く置いたままにすると自動で読み取ります。NDEF 編集かバイナリ編集で内容を変え、［タグに書き込む］で書き込みます。

コード署名をしていないため、初めて起動するときに Windows の SmartScreen の確認が出ます。手順は Wiki の インストール にあります。

いまの制限

  • Windows（x64）専用です。macOS・Linux 向けの配布物はありません。
  • Sony PaSoRi などストレージ方式のリーダーでは、NTAG のパスワード認証・NFC カウンタ・署名の読み取りは使えません。
  • ACR122U などのリーダーと MIFARE Classic は、仮想リーダーでだけ確かめています。
  • FeliCa は Lite-S だけに対応しています。交通系 IC などには対応していません。
